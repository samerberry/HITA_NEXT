# 本地备份

“更多 → 常用入口与公告之间 → 备份与恢复”使用系统文件窗口保存和选择 `.hita-backup` 文件。

备份包含全部课表、科目、课程/考试等事件、颜色、自定义作息、教务更新基线、提醒和课表显示设置、深色模式、当前课表，以及课表图片/视频与服务卡片背景及取景。不包含教务账号凭据、助手密钥、通知记录、手机日历同步登记。

恢复前先校验并展示摘要。课表以新编号和“（恢复）”后缀加入，保留已有课表；提醒、显示和背景按备份替换。新编号不会继承原手机的日历同步登记。

## 格式 v1

- 8 字节 ASCII `HITABK01`。
- 4 字节小端无符号整数：UTF-8 JSON 元数据长度。
- 32 字节：元数据 SHA-256。
- JSON 元数据：`BackupManifest`，最多 16 MiB。
- 按 `assets` 顺序紧接原始媒体字节，每项包含角色、长度、SHA-256。

媒体只允许五种角色：`poster`、`video`、`widgetSource`、`widgetCompact`、`widgetWide`。文件路径全部在当前设备生成，不从备份读取。媒体分块传输，保留原文件字节，不限制图片或视频分辨率。

## 一致性

导出通过单一数据库事务读取。恢复预先校验媒体，在单一写事务中插入全部课表与恢复凭据；设置和背景发布前写入本地恢复日志。异常时回滚数据库并恢复旧设置与背景；进程中断后，在主页和提醒服务启动前依据数据库凭据完成或回滚。旧媒体在提交后清理，缓存中的导出和预览文件在取消、关闭或下次启动时清理。

`scripts/backup.test.cjs` 覆盖数据/媒体往返、完整性校验、设置回退、启动恢复、敏感信息排除和窗口入口；`scripts/database-integrity.test.cjs` 使用 SQLite 验证快照、事务回滚与空课表。
