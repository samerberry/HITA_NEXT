# HITA NEXT 1.0.0 提审文案

## 商店简介

HITA NEXT 是由独立开发者发布和维护的第三方鸿蒙课表与学习管理工具，独立于哈尔滨工业大学及其教务系统。校名和校区名称仅用于说明适用对象与教务信息来源。

你可以查看当天安排、下一节课的时间、地点及倒计时，也可以按教学周浏览课表。应用支持手动添加和编辑课程、管理多份课表、导入或导出 ICS 日历文件、同步至手机日历，以及自定义课前提醒、记录作业和考试复习待办。手动管理课表、导入 ICS 日历和记录学习待办可独立使用。

教务功能可选。用户可在应用内打开所选校区的校方网页，使用本人账号并按网页提示操作。校方网页可能要求输入账号、密码或验证码，由校方处理。应用在本机保存校方返回的会话，用于导入课表和查询考试、成绩及空教室等信息。用户可通过「更多」顶部入口点击「删除数据」，移除所选校区的会话及账号资料。

查询和导入的范围取决于校区系统、账号权限及网络状况。应用只读取教务数据，编辑课表和待办只影响个人记录。选课、调课等教务事务由校方渠道办理，课程变动、考试安排、成绩及教室使用情况以学校教务系统和正式通知为准。

## 审核备注

华为审核团队您好。HITA NEXT 是独立开发的第三方课表工具，无独立账号体系，打开应用及使用本地功能均无需注册或登录。教务导入是可选的数据读取功能。用户在校方网页登录的是所选校区的教务系统，账号及验证码由校方校验。HITA NEXT 仅凭校方会话读取用户有权访问的教务数据，应用内编辑仅影响个人记录。「辅助功能」中的教务考试、成绩、学分和空教室查询也依赖有效的校方会话。随附 DOCX 含完整的虚构 ICS 数据及本地导入复测步骤。随附真机 MP4 演示校方网页、教务导入与查询，敬请确认可否作为教务部分的补充审核材料。
