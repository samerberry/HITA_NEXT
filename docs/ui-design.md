# HITA NEXT 界面规范

本轮按本地 HarmonyOS 设计技能统一应用页面，使用现有 ArkUI 与材质兼容层。

## 视觉与布局

- 公共尺寸与字号在 `common/theme/HitaDesign.ets`：展示 28、页面标题 22、分区标题 18、正文 16、辅助文字 14、标签 12 fp。
- 页面左右留白 16 vp，卡片间距 12 vp，分区间距 24 vp；卡片圆角 16 vp，输入框圆角 12 vp。
- 主按钮高度 48 vp；设置入口最小高度 72 vp。表单使用固定标签宽度和可伸缩输入区。
- 色彩统一从 base/dark 资源读取。中性页面底色承托表面卡片，蓝色用于主操作、选中态与重点信息。
- 普通正文、辅助文字和主操作文字在对应不透明表面上满足 4.5:1 对比度，自动检查见 `scripts/design-contrast.test.cjs`。
- 时间表网格保留紧凑字号和用户自定义课程颜色，避免通用字号放大后损失整周信息密度。

## 材质与交互

- 导航与操作控件沿用现有官方材质及 API 兼容分支。普通整页表单使用不透明表面，避免大面积透明层影响阅读。
- 设置入口箭头使用原生 SymbolGlyph，保持普通样式；不单独为箭头增加材质。
- 课表管理入口显示图标和文字，课表卡片显示名称、日期与当前状态；长按选择行为保留。宽度达到 600 vp 时使用双列。
- 课程详情的编辑与删除/翘课操作使用 48 vp 按钮；通过原有路径进入编辑，保留编辑范围与保存语义。
- 课程、考试及日程表单统一输入区层次，课程的星期、教学周手势不变。
- 底部弹层继续遵循 `AGENTS.md`：`SheetContent` 单层包裹、顶部 24 vp 留白、固定高度使用 `fillHeight`，关闭动画结束后清理内容。

## 验证记录

- DevEco `assembleHap` debug 构建通过，811 项自动化检查通过。
- 手机模拟器检查：今日、更多、时间表、课表管理、课表详情、课程详情与编辑、星期及教学周选择、考试编辑、深色模式、备份与恢复。
- 备份固定高度弹层检查遮罩、返回、下滑关闭及重新打开；课程详情自适应弹层检查返回关闭及重新打开。
- 考试、成绩、空教室检查了登录过期界面；在线数据成功态、平板和真机性能仍需使用有效账号及对应设备验收。
