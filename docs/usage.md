# HITA NEXT 使用说明

## 今日与时间表

- 今日显示日期、当天安排以及正在进行或即将开始的课程。
- 未添加课表时显示空态，不生成演示课程。
- 时间表以周视图展示课程，左右滑动切换周次，上下滚动查看其他时段。
- 查看其他周时，右下角显示「回到本周」浮动按钮；点击返回今天所在的教学周，保留当前纵向滚动位置。今天不在所选课表范围内时不显示。
- 当前查看的周有 18:30 及以后开始的课程，且页面尚未滚至底部时，右下角显示圆形下箭头。点击滚动到课表底部，接近底部时按钮自动隐藏；切周后重新判断。与「回到本周」同时出现时，下箭头在下，回到本周按钮在上。
- 点击时间表中的课程或考试，可以查看详细信息。
- 时间表右上角调色盘调整标题、日期和时间刻度的文字颜色；课程详情右上角调色盘调整该课程所有周次的课块颜色。
- 调色面板支持彩虹色相条、直接点选或拖动颜色区域，以及快捷色。保存后生效并保存在本地；取消不修改原颜色。课块沿用亮色压暗规则，预览显示实际课块效果。

## 登录与导入

1. 进入「更多」，点击顶部教务会话卡片。
2. 选择校区，在学校统一身份认证网页中完成登录。
3. 返回「更多 → 导入课表」，确认学期、开始日期和节次时间后导入。
4. 已有日历文件时，可通过「导入 ICS 课表」导入。

登录和教务查询需要网络连接。已导入的课表保存在本地，可以离线查看。

成绩、考试、空教室或课表请求明确返回登录过期后，「更多」里的对应教务账号会显示「已过期教务」，头像底色变红；重新登录成功后恢复。进入「更多」或打开账号弹层只读取已保存状态，不额外检查连接。网络超时或服务故障不会直接标为过期。

## 课表管理

- 「最近课表」打开最近学期的课表详情。
- 「课表管理」可以选择已有课表、新建空课表、导入或删除课表。
- 课表详情支持调整开始日期、添加或编辑课程、删除课次，以及修改科目属性。
- 删除前请确认所选课表或课程，必要时先导出 ICS。

## 手动添加课程

- 在「时间表」右上角点击「＋」，或在「更多 → 最近课表／课表管理 → 课表详情」点击「添加课程」，使用同一套表单，保存到对应课表。返回时间表时保留原来查看的教学周。
- 添加页按「课程信息 → 上课时间 → 上课日期」填写。课程名称必填，教室和教师选填；底部显示缺项提示或预计课次数，必填内容有效后「添加课程」按钮才可用。
- 「单日」通过系统月历选择具体日期；「每周」可以同时选择多个星期几和多个教学周。例如周一、周三 × 第 2、3 周，会生成 4 个课次，使用相同的名称、地点、教师和起止时间。
- 教学周支持「全部／单周／双周／清空」。星期、教学周都可逐个点选或横向滑动连续选中／取消，纵向滑动正常滚动页面。
- 教学周按目标课表的开学日期计算，可点击周数格子末尾的「＋」增加 5 周继续选择；保存前至少选择一个星期和一个教学周。新增课次超出原结束日期时，会提示并将课表延长至最后课次所在周的周日，范围更新与课次一起保存。单日早于开学日期时不能保存，避免改变既有教学周编号。
- 上课时间可选「按节次」或「具体时间」；节次使用当前课表自己的作息，显示对应起止时刻。切换模式保留各自的选择，保存时只使用当前模式。
- 点击「选择已有课程」可带入名称、教室和教师，并沿用所选科目的颜色与关联；教室、教师仍可修改。点击「手动填写」退出已有课程选择。没有课次的科目也可以选择。
- 一次添加的多个课次一起保存，失败不会留下部分课次。已有同名科目会继续使用其颜色和属性；编辑已有课次默认「仅本次」，也可选「选定周次」或「之后所有」。范围按课程 ID 和课表 ID 匹配，同名的其他课程不受影响。只同步修改过的字段，未修改的教师、教室和时间差异会保留。调整日期时，各课次按相同天数平移。

## 课程、考试提醒与手机日历同步

- 在「更多 → 课程与考试提醒」分别开启课程、考试提醒，通过系统选择窗口设置各自的提前时间（1–120 分钟，默认课程 15 分钟、考试 60 分钟）。
- 应用通知在 HITA 前台或后台运行期间生效，点击通知可打开对应课程或考试详情。被系统结束进程后，应用内通知无法继续发出。
- 在「更多 → 课表工具 → 同步至手机日历」弹窗中设置「自动同步」，点击「保存」生效。首次开启需要允许日历读写权限；同步按课表分别保存，取消或关闭弹窗不会应用开关改动。
- 系统日历中会出现「HITA · 课表名称」，包含该课表全部课程、考试及其他有效日程的实际日期、时间、地点和教师信息。
- 调课、改教室、停课、删除、撤销或教务更新后会自动更新日历。提醒开关与提前时间也会同步；连续的同一门课只在开始前提醒一次。已由日历接管的课次不会再发重复的应用通知。
- 同步失败时保留登记并显示失败状态，可在同步弹窗中保持开启并点击「保存」重试；重新启动或回到应用前台也会补同步。部分写入失败后重试不会重复添加。
- 清空或删除课表会移除对应同步日程；关闭同步会清理该课表的同步日程。仅操作 HITA 创建的日程，保留用户自行添加的内容与其他日历。
- 手机日历中的日程与提醒在 HITA 进程退出后仍由系统管理，是否发出提醒受手机日历通知、该日历提醒开关及系统设置影响。若在手机日历中关闭提醒，HITA 下次同步会显示提示。

## 其他功能

- 考试：查看本地考试，手动添加、编辑和删除；支持本部、威海本科教务查询及原有深圳查询。
- 成绩管理：支持深圳、本部和威海本科成绩查询、学期切换与统计；深圳沿用本研教学平台的培养层次参数。
- 助手：根据本地课表回答课程安排问题；云端模型为可选设置。
- 资讯：博客订阅 HOA；通知按最近一次登录时选择的校区加载，深圳为深圳信息网、本部为今日哈工大、威海为今日哈工大（威海）。未登录时默认显示本部通知，刷新会重新读取校区；各校区均从最新一页开始加载。若通知网站要求认证，可点“打开通知网站”，完成认证后返回重试。
- 更多：课程与考试提醒、日历同步、公告和教务会话管理。
- 空教室：按教学楼、学期和周次自动查询三校区本科教务记录，点击教室查看每天各节占用。

## 成绩查询与统计

1. 在「更多 → 成绩管理」选择校区、学期与成绩类型。首次进入优先使用最近登录的可用校区会话、当前学期；切换选项后自动查询，右上角可刷新。
2. 深圳支持期末、期中；本部和威海本科还可选择全部、重修。所选校区没有教务会话时提示登录；会话失效、接口异常和确实没有成绩分别显示。
3. 点击成绩卡片查看课程代码、学分、学时、课程性质、类别及开课单位。
4. 官方统计只显示教务实际返回的字段。深圳使用所选学期的 GPA、学分绩及排名；本部和威海显示教务累计学分绩与排名，页面明确标注统计范围。缺失字段显示「—」，不推算 GPA 或排名。
5. 本地统计仅按当前列表计算课程数、通过情况、学分、平均分和学分加权均分。均分仅统计 0～100 的数值，等级制不换算百分制；未识别或未公布成绩单列为待定。期中成绩可能采用不同满分或折算方式，仅显示原始数值的均分，不推断课程是否通过。它不等于官方 GPA、毕业学分或排名，官方统计暂时失败不会隐藏已经获取的成绩。

本部、威海研究生成绩接口暂未接入。三校区真实账号的返回内容仍须与学校系统核对。

## 考试查询

1. 在「更多」的教务会话入口登录所需校区，再进入「考试查询」，点击右上角「查询」。
2. 使用最近登录的校区会话。本部、威海优先读取考试页面选中的学期，分别查询期末、期中与补考，结果显示校区和学期。
3. 点击教务考试查看课程名称、日期、起止时间、考场和考试类型；点击「导入到课表」保存至当前课表，之后可在时间表和考试列表查看、编辑或删除。
4. 未公布日期或完整起止时间的考试仍会显示，但不能直接导入，避免生成错误时间。可以通过右上角「添加」手动补充。
5. 部分类型查询失败会明确提示，不会当作“没有考试”。会话过期时需重新登录；研究生考试接口尚未接入本部、威海。

本部、威海实现参考安卓与 iOS 的本科教务接口，真实账号的查询结果仍需按学校实际发布内容核对。

## 空教室查询

1. 在「更多」顶部教务会话卡片中登录所需校区，再进入「空教室」。查询使用应用当前选用的教务账号，支持本部、威海、深圳本科教务。
2. 顶部横条从左到右为教学楼、学期、周次。进入页面、变更任一选择后自动查询，无需另点查询按钮。周次选择范围与安卓 3.0.0 一致，为第 1～20 周。
3. 初次进入选当前学期、第一栋教学楼。周次取对应校区已导入课表的当前周；没有对应课表时选第 1 周。右上角刷新会重新加载选项和结果。
4. 教室以双列卡片显示「空闲／被占／将占／未知」。与安卓一致，状态按**所选周的占用表**，结合今天的星期和当前节次判断；查看其他周时不能把卡片当成实时现场状态。
5. 点教室打开底部详情，默认选今天，可切换周一至周日，逐节查看时间及「空／占用／未知」。星期切换直接使用已查询的整周数据。

有历史查询时先显示缓存，再更新网络数据；缓存标明保存时间，更新失败时保留提示。初次加载学期和教学楼仍需要网络。空闲只表示教务系统未登记占用，不保证教室实际开放。

没有登录或会话失效时可以进入教务账号页面，登录后返回重试。其他加载错误同样提供重试和教务账号入口。深圳未获取到实际节次时间时，卡片显示未知，详情提示刷新；不会套用其他校区时间。本部研究生接口尚未接入。


教务导入的教学周范围按实际课次确定（例如最后一节课在第 17 周，则默认到第 17 周），不再固定为至少 25 周。旧版导入且仍保留默认 25 周结束时间的课表，会按已有课程和日程修正范围；手动指定的其他范围不变。

## 问题反馈

反馈时说明应用版本、设备型号、校区、复现步骤和实际提示。
分享截图或日志前，请遮挡姓名、学号、Cookie、验证码和其他个人信息。

### 批量调课与停课

- 时间表点进课程详情，在右下角「翘课」左侧点击「编辑」；课表详情内点进具体课次使用同一详情样式，右下角操作为「编辑／删除」。按钮采用兼容系统版本的华为官方材质。
- 编辑器先选择应用范围，展示受影响课次数；「选定周次」影响所选周内本课程的全部课次。「之后所有」从打开的课次开始计算，包含该课次。
- 开启「停课」后确认，会从本地课表移除所选课次，保留课程科目及考试。调课、停课完成后可在结果窗口点击「撤销」，关闭窗口后结束本次撤销。
- 批量操作和撤销均原子保存；若期间课表已被其他操作修改，会拒绝覆盖，请关闭编辑器刷新后重试。调课延至学期结束后时，课表结束日期自动延长；撤销后保留延长的日期范围。
- 课表详情中的彩色条仅展示颜色。修改课程颜色需进入具体课次的详情，点击右上角调色盘，与时间表操作一致。
