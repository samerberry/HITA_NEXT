# 使用本地数据

打开“更多”顶部账号卡，在任一未登录校区点击“登录教务系统”左侧的圆形盾牌图标七次，再点击“确认使用本地数据”。点击之间没有时间限制，切换校区或关闭面板会重新计数。单击“网页登录”仍直接使用所选校区的校方网页。

成功后保存本地演示会话，并自动导入、选中演示课表。已保存的真实校区会话不会被测试会话覆盖。重启后保留登录状态；可从账号管理正常退出或重新登录。演示会话没有学校 Cookie、Token 或保存的密码，HTTP 客户端和静默续期都禁止它访问真实教务。正常账号继续使用原认证流程。

## 展示内容

- 登录后，“更多”账号卡片显示“已登录”，账号管理面板显示“本地账号”及“已登录”标签。两处原校区位置均显示“本地数据”。旧本地会话中的占位账号信息会在读取时清除。
- 课表来自用户提供的 `课表-2026-2027-1.ics`：21 个课程名、193 个课次，保留课程、教师、地点和实际起止时间。第1周从 2026-08-31 开始；课次从 2026-09-07 至 2027-01-05。
- 各校区共用同一份内置课表，保留既有的 `DEMO:SHENZHEN:2026-20271` 来源编码。重复导入复用同一张课表，退出本地会话后仍可查看。
- 学分查询沿用本地课程汇总；ICS 不含学分，不凭空编造学分。
- 成绩管理、考试显示暂无；考试页不读取此前保存的考试或复习任务。
- 空教室页面标注“本地数据”，包含视频中的23个选项，仅9栋已展示教室的楼宇提供72间教室的演示占用数据，其余显示暂无数据。清单与视频时间点见 [demo-classrooms.md](demo-classrooms.md)。
