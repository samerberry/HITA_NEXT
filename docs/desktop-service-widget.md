# 桌面服务卡片

所有桌面卡片共用 24 vp、8 vp 圆角的应用图标；有品牌字标时统一使用 14 fp 粗体。2×2「学习日程」左上角只显示应用图标，右上角是课程、考试和待办分段按钮。其他卡片左上角保留应用图标和“HITA NEXT”字样。「学习日程」的三个页签可以在桌面直接切换：

- **课程**：显示当前课表中正在上的课，或今天的下一节课。倒计时用“1时25分”“45分”“2时”单行显示。上课后切换为下课倒计时；两种 2×2 课程视图的进度环直径均为 48 vp，放在倒计时右侧，圆环外沿的最低点与「后下课」三个字的可见底缘对齐。小时达到三位数且显示不下时，仅时间文字横向滚动。
- **考试**：显示本地各课表中正在进行或即将开始的考试，包括起止时间和考场。考试结束后自动移出。
- **待办**：在卡片内上下滑动浏览未完成的作业和复习。按实际截止时间从早到晚排序，同一截止时间先显示先添加的，无截止日期的排在最后。全天待办到当天结束才算逾期。

考试在 2×2 卡片上显示首场，在 2×4 上最多并排显示两场；待办在两种尺寸上都可滚动。点击考试打开考试详情，点击一条作业或复习直接打开该条的「编辑待办」。如果当前待办有未保存的修改，切换前会询问是否保留。应用内「今日」的待办入口仍先打开列表。卡片只读取本地数据，不查询教务，也不向桌面发送账号、会话或待办备注。

添加方式：

1. 打开 HITA NEXT，在“更多”页面的“课表工具”中点击“桌面服务卡片”。
2. 在系统服务卡片管理页选择 HITA NEXT，添加到桌面。

在“桌面服务卡片”展开的二级菜单中，第一行“设置桌面服务卡片”打开系统卡片管理页，第二行“自定义背景”可从图库选图：分别为 2×2 和 2×4 卡片拖动、双指缩放或用滑杆选择显示区域（100% 为刚好铺满，更小则完整显示、空白处保留白底），并可调整白色蒙版以保证文字可读。保存时按卡片比例烘焙图片，卡片端以 `backgroundImage` + `ImageSize.Cover` 居中显示，不再拉伸或二次裁切；`backgroundImageResizable` 不支持在 ArkTS 卡片中使用，且属于九宫格拉伸，因此未采用。

也可以长按桌面上的 HITA NEXT 图标，选择“服务卡片”。已有的“学习日程”保持不变，提供 2×2 和 2×4。应用内“设置桌面服务卡片”也可以按名称选择以下新卡片：

- **课程进度**（2×2、2×4）：只显示课程。上课前显示倒计时，上课后显示进度环与下课倒计时，不设其他页签。沿用原课程卡片的自定义背景。
- **课表**：2×4 保留本周日期选择和「课表 / 待办」切换。点日期查看当天的课程和考试；待办按截止时间、创建时间排序，点一项直接进入编辑。

4×4 和 4×6 课表卡片左上角是圆角 HITA NEXT 图标与名称，右上角显示所选日期的月份，在学期内也显示对应的教学周。下方 44 vp 高的日期栏按周日到周六排列，只显示星期和公历日号。有安排的日期下方有一条短线；默认选中今天，用品牌蓝实底，点其他日期则用浅蓝底。

点选日期，下方按开始时间列出当天的全部课程和考试。安排结束后保留在原位，右侧状态更新为「已结束」。只有全天没有安排时才显示摊开的蓝色课表插图。

4×4 和 4×6 的每个课程块都带蓝色竖线，高度固定为 64 vp。条目超出卡片可见区域时，上下滑动列表即可查看，其高度不随数量变化。左侧显示起止时间，中间的名称最多两行，「教室 · 教师」共用一行，缺失字段省略；右侧显示「未开始 / 进行中 / 已结束」和已记录的课程节次。考试在名称前标注「考试」，与课程块等高。点条目可查看详情。4×6 可同时看到更多条目，在系统配置中记作 `6*4`。

卡片按设备本地时间更新；应用退出后，已缓存的课程和考试仍会随起止时间切换。导入、编辑或删除日程、完成待办、切换当前课表后，应用会主动刷新已发布的卡片；后台定时刷新由系统调度。
